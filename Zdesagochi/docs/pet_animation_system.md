# Pet Animation System — Полная спецификация

> Версия 1.0 · Май 2026  
> Охватывает: архетипы питомца, состояния анимации, взаимодействие со сценой

---

## 1. Архетипы питомца

Перед выбором анимации система определяет **архетип** на основе текущей конфигурации частей тела. Архетип влияет на то, как именно проигрывается каждое состояние.

### Логика определения

```
isAnimal    = tail !== 'none'
              || legs in ['paws', 'hooves', 'claw_feet', 'flippers']

isHumanoid  = arms === 'long_arms'
              || outfit !== 'none'
              || (tail === 'none' && legs === 'none' && arms in ['long_arms','stubby'])

isCreature  = !isAnimal && !isHumanoid   // blob, щупальца, плавники, и т.п.
```

### Три архетипа

| Архетип | Типичный облик | Особенности |
|---|---|---|
| **ANIMAL** | Хвост + лапы. Кошко/собако/зверо-подобный | Миска на полу, квадрупедная ходьба, свернуться калачиком |
| **HUMANOID** | Длинные руки или одежда, нет хвоста/лап | Стол с едой, бипедальная ходьба, сидеть на стуле по-людски |
| **CREATURE** | Все остальные (слизень, медуза, щупальца) | Плавное скольжение, поглощение еды телом, деформации |

> **Важно:** один и тот же питомец меняет архетип если игрок в редакторе добавил хвост или сменил одежду. Архетип вычисляется в рантайме при каждом рендере сцены, не кешируется.

## 2. Система состояний — конечный автомат

### Приоритеты (высший побеждает)

```
5 — ACTION      (едим, играем, купаемся)     — запускается кнопкой игрока
4 — REACTION    (испуг, ласка, злость-вспышка) — короткий burst ≤ 3 сек
3 — MOOD        (sick, ecstatic, sad, tired)   — пассивно из pet.mood
2 — BEHAVIORAL  (patrol, bored, sleep)         — idle-поведение
1 — IDLE        (default float)               — базовый float всегда
```

Состояния `ACTION` и `REACTION` автоматически возвращают управление предыдущему слою через таймер.

## 3. IDLE-состояния (BEHAVIORAL + MOOD слои)

### 3.1 IDLE_FLOAT — базовый режим

**Триггер:** нет других активных состояний  
**Реализация:** текущий `floatAnim` из `PetDisplay` (y: [0,−10,0])  
**Изменения:** нет, уже работает

---

### 3.2 SLEEPING — сон

**Триггер:** `pet.isAsleep === true`

**Логика кровати:**
- Система ищет первый `PlacedFurnitureItem` с `itemId === 'bed'` в `placedFurniture`
- Если кровать **есть на сцене** → питомец перемещается к её X-позиции и "ложится" на неё. Новая кровать **не создаётся**, используется существующая
- Если кровати **нет** → питомец ложится в центре у пола (fallback)

**По архетипу:**

| Архетип | Анимация |
|---|---|
| ANIMAL | Сворачивается на боку — `rotate: 30, scaleX: 1.3, scaleY: 0.7` |
| HUMANOID | Ложится на спину — `rotate: 90, translateY: +30%` |
| CREATURE | Сплющивается — `scaleY: 0.4, scaleX: 1.4`, медленная пульсация |

**Общие элементы:**
- Slow belly-breathing: `scaleY [1, 1.07, 1]`, duration: 3.5s
- Zzz-буквы (уже есть, усилить — 4 буквы вместо 3, большая амплитуда)
- Затемнение глаз (sleeping mouth уже есть)

---

### 3.3 PATROL — ходит из угла в угол

**Триггер:** mood in ['happy', 'content', 'ecstatic'] + бездействие игрока > 15 сек  
**Сброс:** любое ACTION, REACTION, или взаимодействие игрока

**Механика движения:**
```
xPositions: [-38%, 0%, +38%]  — три точки маршрута
Питомец выбирает следующую точку рандомно из двух оставшихся
При смене направления: scaleX флипается (разворот)
Между точками: пауза 1.5-3 сек (рандомно)
```

**По архетипу:**

| Архетип | Походка |
|---|---|
| ANIMAL | Лёгкое покачивание тела `y: [0, -4, 0]` синхронно с шагом |
| HUMANOID | Боковое раскачивание плеч `rotate: [-1, 1, -1]`, легкий bob |
| CREATURE | Плавное скольжение без покачиваний, слабая пульсация тела |

**Взаимодействие с мебелью во время патруля:** см. раздел 5

---

### 3.4 TIRED — вялость

**Триггер:** `pet.mood === 'tired'`

**Анимации:**
- Замедленный, тяжёлый float: `y: [0, -3, 0]`, duration: 5.5s
- Периодически голова падает вниз: `rotateX: [0, 22, 0]`, duration: 2.5s, repeatDelay: 4s
- Глаза полузакрыты (новый eyeStyle `'half'` или через `scaleY: 0.5` на existing eye groups)
- Над головой периодически появляется `😴` и медленно исчезает

**Взаимодействие:** если на сцене есть диван/кресло/кровать — питомец медленно плетётся к ней

---

### 3.5 SAD — грусть

**Триггер:** `pet.mood === 'sad'`

**Анимации:**
- Медленный patrol с опущенной головой: `rotateX: 10-15` постоянно
- Периодические слёзы: `💧` частицы падают вниз от глаз
- Вздыхание: тело расширяется и сужается `scaleX: [1, 1.06, 1]` медленно

**Взаимодействие с мебелью:**
- Если **зеркало** на сцене: питомец подходит, долго смотрит на отражение, голова опускается ниже
- Если **кубок** на сцене: питомец отворачивается, делает шаг прочь
- Если **сакура** на сцене: садится под ней, поднимает взгляд на ветки

---

### 3.6 SICK — болен

**Триггер:** `pet.mood === 'sick'`

**Анимации (добавить к существующим x-глазам):**
- Вудзи-вобл: `rotate: [-4, 4, -4]`, duration: 0.9s (зеленоватый woozy)
- Над головой плавает `🤢` (replaces обычный speech bubble)
- CSS filter: `hue-rotate(80deg) saturate(1.3)` — зеленоватый оттенок на весь SVG
- Периодически питомец "наклоняется" вперёд: `rotateX: 15` и возвращается

**По архетипу:**

| Архетип | Вариант |
|---|---|
| ANIMAL | Садится, прижимает уши |
| HUMANOID | Держится за живот (arms анимируются вниз к телу) |
| CREATURE | Нерегулярная пульсация, части тела ненадолго смещаются |

---

### 3.7 ECSTATIC — в восторге

**Триггер:** `pet.mood === 'ecstatic'`

**Добавить к существующим sparkles:**
- Серия прыжков: `y: [0, -50, 0, -30, 0, -15, 0]`, duration: 2s, repeat
- Мини-спины: `rotateY: [0, 180, 360]` раз в 8 секунд
- Вокруг летают `✨ 🌈 ⭐` (уже есть основа, расширить набор)
- Масштабирование при прыжке: `scale: [1, 1.12, 0.92, 1.08, 1]` (squash & stretch)

## 4. ACTION-состояния (запускаются кнопками)

### 4.1 EATING — кормление

Самое важное состояние с точки зрения архетипов.

#### ANIMAL — миска на полу

**Визуал:** перед питомцем появляется emoji-миска (`🥣`) в виде CSS-элемента  
**Питомец:**
1. Разворачивается к миске
2. Наклоняется: `translateY: +20px, rotateX: 20deg`
3. Голова делает 4-5 быстрых "клевков" к миске (y bounce)
4. Миска анимируется: появляется → еда убывает → исчезает
5. После: поднимается, `content` выражение, довольный выдох

#### HUMANOID — стол с едой

**Варианты стола (выбирается рандомно или по теме комнаты):**

| Вариант | Вид | Подходит для |
|---|---|---|
| **Пикник-коврик** | Emoji `🧺` + `🍎🥪` разложены на полу | Casual / природные темы |
| **Поднос** | `🍽️` с едой несёт в руках, затем ставит | Любой стиль |
| **Стол** | CSS прямоугольник + `🍜` или `🍕` на нём | Городские/домашние темы |

**Питомец (humanoid eating):**
1. Появляется выбранный стол/поднос рядом
2. Питомец подходит, садится или встаёт у стола
3. Рука (arms) анимируется к еде: `translateX, translateY` к блюду
4. Голова наклоняется, жевательное покачивание
5. Еда уменьшается (`scale: 1 → 0`)
6. После: `😋` bubble, поглаживание себя по голове (arm animation)

#### CREATURE — поглощение

**Визуал:** еда `🍎` летит по дуге к телу питомца  
**Питомец:**
1. Еда материализуется рядом
2. Летит к центру тела питомца (parabolic trajectory)
3. При контакте: тело кратковременно расширяется `scale: 1 → 1.2 → 1`
4. Ripple-волна по телу
5. После: `😊` и свечение тела усиливается на 2 секунды

---

### 4.2 PLAYING — игра

**Длительность:** 8–12 секунд, затем возврат в idle

#### ANIMAL
1. Прыгает на воображаемый мячик: `y` прыжки + боковые смещения `x`
2. Крутится — пытается поймать хвост (если хвост есть): `rotate: 360`, быстро
3. Вокруг летят `🎾 🧶 ✨`
4. В финале: падает на бок, отдыхает (переход в TIRED на 3 сек)

#### HUMANOID  
1. Подбрасывает мяч: рука (arms) animation вверх, `🏀` летит по дуге и падает
2. Прыжок-хлопок: прыжок + `rotate: ±15` в воздухе
3. Вокруг летят `🎮 ⭐ 🎯`
4. В финале: высокое пятёрка себе, `😤` → `😊`

#### CREATURE  
1. Хаотичные упругие прыжки во все стороны: `x, y` рандомные keyframes
2. Тело деформируется при каждом "ударе о пол": squash & stretch
3. Вокруг распыляются пузыри `🫧`
4. В финале: вращение и плавная остановка

---

### 4.3 CLEANING / BATHING — гигиена

**Длительность:** 5–7 секунд

**Анимации:**
- Мыльные пузыри `🫧` поднимаются со всего тела
- Мерцание: питомец briefly становится чисто-белым и возвращает цвет
- Sparkle-вспышка в конце (чистый и блестящий)

**По архетипу:**

| Архетип | Движение |
|---|---|
| ANIMAL | Лижет лапу и трёт ухо, потряхивается |
| HUMANOID | Тянется вверх, трёт голову обеими руками (arms down→up) |
| CREATURE | Вращается вокруг оси, пузыри стекают |

---

### 4.4 MEDICINE — лечение (при sick)

**Длительность:** 4–5 секунд  
**Визуал:** `💊` или `💉` emoji появляется, питомец взаимодействует с ним  
**Анимации:**
- Питомец отворачивается (нехочет): `rotate: ±30`
- Потом соглашается: возвращается
- "Глотает": короткое движение вверх-вниз горла
- После: зелёный hue-filter исчезает (lerp 1s), выражение меняется на content

---

### 4.5 PETTING — поглаживание (тап на питомца)

**Длительность:** 2–3 секунды

**Анимации:**
1. Испуг: `scale: [1, 0.85, 1.15, 1]` за 0.3s (уже есть как REACTION)
2. Признание: глаза в форме ❤️ (brief eyeStyle override → 'cute' с красным цветом)
3. Сердечки: `❤️ 💕` летят вверх от головы
4. Лёгкое мурчание/покачивание: `rotate: [-2, 2, -2]`, duration: 1.5s
5. После: `😊` выражение на 3 секунды

## 5. Взаимодействие питомца с предметами сцены

Система **Scene Interaction** — ключевая фича. Работает так:

```
1. Раз в N секунд (зависит от mood) — выбирается ближайший подходящий предмет
2. Питомец перемещается к нему
3. Запускается interaction-анимация на 4-8 секунд
4. Предмет анимируется отдельно (через updateRoomFurniture или CSS override)
5. Питомец возвращается к обычному маршруту
```

Предметы, **НЕ** поддерживающие взаимодействие: `onWall: true` предметы (картина, зеркало — отдельная логика), люстра, дверь.

---

### 5.1 🛏️ КРОВАТЬ

| Состояние питомца | Взаимодействие |
|---|---|
| `isAsleep` | **Использует кровать как место сна** (см. 3.2). Питомец перемещается на кровать |
| `mood === 'tired'` | Питомец плетётся к кровати, несколько раз смотрит на неё, потом уходит (скучает) |
| `mood === 'happy'` | Прыгает на кровать, немного попрыгав → bounce animation |

---

### 5.2 🛋️ ДИВАН / 🪑 КРЕСЛО

| Состояние | Взаимодействие |
|---|---|
| `tired` / `sad` | Питомец подходит, **плюхается** на диван. HUMANOID: садится вертикально. ANIMAL: запрыгивает и сворачивается. CREATURE: обтекает форму дивана |
| `happy` / `content` | Случайно: запрыгивает и сразу соскакивает с дивана, как будто тестирует |
| `ecstatic` | Прыжки на диване (y bounce, диван слегка squash при каждом прыжке) |

**Анимация дивана:** при "плюхе" — кратковременный `scaleY: 1 → 0.92 → 1` через `updateRoomFurniture`

---

### 5.3 📺 ТЕЛЕВИЗОР

| Состояние | Взаимодействие |
|---|---|
| `bored` (idle > 60s, mood: content/sad) | Питомец садится перед ТВ, смотрит. Глаза питомца отражают свет экрана (brightness пульс) |
| `happy` | Смеётся перед экраном: быстрый bounce, `😂` bubble |
| `tired` | Засыпает перед ТВ: сначала смотрит, потом голова падает, Zzz |

**Анимация ТВ:** при просмотре — `hue` предмета медленно крутится (смена каналов), emoji меняется на `📺→🎬→📺`

---

### 5.4 🎮 ПРИСТАВКА

| Состояние | Взаимодействие |
|---|---|
| `ecstatic` / `happy` | Питомец хватает контроллер. HUMANOID: яростно жмёт кнопки (arms быстро дёргаются). ANIMAL: бьёт лапами. CREATURE: облепляет контроллер |
| Во время PLAYING action | Приставка светится, вокруг питомца летят `🎮 ⭐ 💥` |

---

### 5.5 🖥️ КОМПЬЮТЕР

| Состояние | Взаимодействие |
|---|---|
| `bored` / `content` | HUMANOID: садится, "печатает" (arms вперёд, мелкие вибрации). Экран светится. Над головой `💭` с текстом "..." |
| LED/Hologram eye стиль | Дополнительно: глаза синхронизируются с цветом экрана |

---

### 5.6 🎵 МУЗ. ЦЕНТР

| Состояние | Взаимодействие |
|---|---|
| `happy` / `ecstatic` | Питомец танцует рядом. Вокруг него визуализация звука: круги расходятся волнами. `🎵 🎶` летят от центра |
| `sad` | Питомец грустно смотрит на него. Пузырь с `🎵` появляется, питомец отворачивается |

---

### 5.7 🌵 КАКТУС

Самый богатый на интеракции предмет.

| Состояние | Взаимодействие |
|---|---|
| `sad` / `angry` (через mood) | **Питомец пытается повалить кактус:** подходит, толкает → кактус наклоняется (`tiltY: 0 → 25 → -10 → 5 → 0`), питомец отшатывается (`x` резкий прыжок назад). Повторяет 2-3 раза. В конце кактус остаётся немного tilted на `5` |
| `sick` | Питомец стоит рядом, выглядит сочувственно (как сам кактус "тоже страдает"). Зеленоватый оттенок у обоих |
| `happy` | Гладит кактус рукой (HUMANOID) или нюхает (ANIMAL). Сразу отдёргивается (`ouch!` bubble), кактус дрожит. `😅` выражение |
| `ecstatic` | Обнимает кактус невзирая на шипы, сердечки `❤️`. Кактус briefly светится от радости |

**Анимация кактуса:** `rotation` и `tiltY` через внутренний state, не через `updateRoomFurniture` (чтобы не сохранялось). Возврат в `tiltY: 0` за 2 секунды после интеракции.

---

### 5.8 🪴 ГОРШОК / 🌴 ПАЛЬМА

| Состояние | Взаимодействие |
|---|---|
| `bored` | Трогает листья (покачивание растения). HUMANOID: наклоняется и нюхает |
| `sad` | Поливает (сверху появляется `💧` и падает в горшок) — HUMANOID only |
| `ecstatic` | ANIMAL: прыгает вокруг пальмы. HUMANOID с ANIMAL: пытается залезть — `translateY` вверх, потом падает |

---

### 5.9 🌸 САКУРА

| Состояние | Взаимодействие |
|---|---|
| `happy` | Ловит падающие лепестки (`🌸` анимируются вниз, питомец тянется к ним) |
| `sad` | Садится под деревом, задумчиво смотрит вверх. Лепестки падают медленнее |
| `ecstatic` | Встряхивает дерево (tiltY покачивание), сакура осыпается лепестками интенсивнее |

---

### 5.10 🍄 ГРИБ

| Состояние | Взаимодействие |
|---|---|
| `curious` (content + idle) | Питомец тычет в гриб: гриб bounce `scale: 1 → 1.1 → 1`. CREATURE: пытается сесть на него |
| `sick` | Пытается съесть. "Нет!" reaction: питомец откусывает, потом ещё хуже выглядит (brief ecstatic → worse sick) |

---

### 5.11 🪞 ЗЕРКАЛО (на стене)

Особый случай — `onWall: true`, питомец к нему не подходит. Взаимодействие визуальное.

| Состояние | Взаимодействие |
|---|---|
| `happy` / `ecstatic` | В зеркале отображается "отражение" — дополнительный PetDisplay меньшего размера с `scaleX: -1`, смещённый в сторону зеркала |
| `sad` | То же отражение, но оно "плачет" (независимые 💧 от отражения) |

**Реализация:** второй `<PetDisplay>` с `size={60}`, `overrideState` питомца, внутри элемента зеркала.

---

### 5.12 🎨 МОЛЬБЕРТ

| Состояние | Взаимодействие |
|---|---|
| `happy` / `content` | Питомец "рисует": HUMANOID тянется рукой к холсту. На холсте появляются рандомные цветные мазки (`<rect>` или `<circle>` SVG, анимируются появлением) |
| `ecstatic` | Бешеное рисование, мазки по всему холсту, краска "летит" `🎨` |

### 5.13 🏆 КУБОК

| Состояние | Взаимодействие |
|---|---|
| `ecstatic` | Обнимает кубок, прыгает вокруг него, `🥇 ⭐` летят |
| `sad` | Отворачивается от кубка, делает шаг прочь |
| `content` | Смотрит на кубок, тихо кивает головой |

### 5.14 🔮 ШАР / 💎 КРИСТАЛЛ

| Состояние | Взаимодействие |
|---|---|
| Любое | Питомец подходит, долго смотрит. Глаза питомца на секунду меняют стиль на `lens` или `spiral`. Аура питомца briefly усиливает glow |
| `ecstatic` | Питомец и шар пульсируют синхронно |

---

### 5.15 🌙 ЛУНА / ⭐ ЗВЕЗДА / 🌈 РАДУГА (Special)

| Предмет | Состояние | Взаимодействие |
|---|---|---|
| 🌙 Луна | `tired` / `isAsleep` | Питомец тянется к луне, лунный свет (glow) усиливается на нём |
| ⭐ Звезда | `ecstatic` | Прыгает к звезде, briefly "хватает" — звезда уменьшается и возвращается |
| 🌈 Радуга | `happy` / `ecstatic` | Питомец "катается" вдоль радуги (x-движение синхронно с её аркой) |

---

### 5.16 🕯️ СВЕЧА / 🪔 ЛАМПАДКА / 🔦 ФОНАРИК

| Состояние | Взаимодействие |
|---|---|
| Любое | Питомец подходит, гипнотически смотрит на пламя. Глаза отражают свет (brief color override → orange). `😶` выражение |
| `ecstatic` | Пытается задуть: `💨` анимация, пламя/свет гасится (isOn → false), потом питомец пугается и убегает |

## 6. REACTION-состояния (короткие вспышки)

### 6.1 STARTLE — испуг (тап по питомцу)

**Длительность:** 0.5s испуг + 2s recovery  
`scale: [1, 0.8, 1.3, 1]` за 0.3s → `❗` bubble → переход к PETTING (см. 4.5)

---

### 6.2 LEVEL_UP — повышение уровня

**Длительность:** 3–4 секунды  
- Яркая вспышка `scale: 1 → 1.5 → 1`
- Кружение звёзд вокруг
- `⭐ LVL UP!` bubble
- Аура briefly белая вспышка

---

### 6.3 ACHIEVEMENT — достижение

**Длительность:** 2–3 секунды  
- `🏆` падает сверху и приземляется рядом
- Питомец смотрит на него, `😍` выражение
- Конфетти `🎉 🎊` разлетаются

---

## 7. Технические требования к реализации

### 7.1 Новый компонент: `usePetBehaviorState`

```typescript
type BehaviorMode = 
  | 'idle_float'
  | 'patrol'
  | 'sleeping'
  | 'tired'
  | 'sad'
  | 'sick'
  | 'ecstatic'
  | 'eating'
  | 'playing'
  | 'cleaning'
  | 'petting'
  | 'interacting'; // взаимодействие с мебелью

interface BehaviorState {
  mode: BehaviorMode;
  targetX: number;         // % смещение от центра (-50..50)
  facingRight: boolean;
  interactionTarget: string | null;  // uid предмета или null
  actionProps: Record<string, any>;  // доп. данные для рендера
}
```

---

### 7.2 Изменения в PetScene

`PetBody` перемещается из `absolute inset-0 flex items-center justify-center` в свободную `motion.div` с `animate={{ x: behaviorState.targetX + '%' }}`.

Переход между позициями: `transition={{ duration: 1.5, ease: 'easeInOut' }}` — плавное перемещение.

---

### 7.3 Архетип-определитель

Новая утилита `getPetArchetype(store)` → `'animal' | 'humanoid' | 'creature'`, вызывается из `usePetBehaviorState`.

---

### 7.4 Слой Props объектов сцены

Новый компонент `<SceneInteractionProps>` рендерится поверх сцены (zIndex 20):
- Стол/поднос для еды (humanoid eating)
- Миска на полу (animal eating)
- Временные объекты реакций (мяч, мыло и т.п.)

Эти объекты — **не** `PlacedFurnitureItem`, это эфемерные CSS-элементы только для текущей анимации.

---

### 7.5 Анимация мебели при взаимодействии

Для предметов, которые должны реагировать (кактус, диван, кровать):
- **Локальный CSS override** через `useState` в `FurnitureItemVisual` — не сохраняется в store
- Для postural tilts: `tiltY` через внутренний state, восстанавливается через 2s setTimeout
- `updateRoomFurniture` используется только для постоянных изменений (isOn toggle)

---

### 7.6 Приоритет выбора предмета для взаимодействия

При патруле питомец "видит" предметы. Выбор:
1. Отфильтровать предметы с `onWall: false` (наземные)
2. Отфильтровать по совместимости с текущим mood (таблица раздела 5)
3. Выбрать ближайший к текущей X-позиции питомца
4. Cooldown 30 секунд на предмет (нельзя взаимодействовать с одним предметом чаще)
5. Шанс взаимодействия: 40% каждый раз когда питомец "проходит мимо"
